Interaction & Inventory System

A modular and data-driven Interaction & Inventory System for Unreal Engine 5, designed for shooter, survival, RPG, and open-world projects. The system provides a flexible foundation for handling player interactions, item pickups, inventory management, and gameplay items without requiring developers to build these core mechanics from scratch.

Key Features

  • Advanced Interaction System
    • Supports six different interaction modes combining focus-based and proximity-based detection.
    • Focus-based interaction using player line-of-sight.
    • Proximity-based interaction for nearby interactive objects.
    • Supports both instant interaction and hold-to-interact mechanics.
    • Configurable interaction behavior for different gameplay scenarios.
    • Designed to support a wide range of interactive objects and gameplay systems.
  • Inventory System
    • Fully functional inventory with drag-and-drop item management.
    • Item categorization for organized inventory handling.
    • Dynamic inventory capacity based on backpack level.
    • Flexible item management architecture that can be extended with additional item types.
    • Data-driven configuration for controlling inventory and item parameters.
  • Pickup System
    • Supports multiple categories of gameplay pickups.
    • Weapon pickups with support for different weapon categories.
    • Multiple ammunition types linked to specific weapons.
    • Grenades with different gameplay functionality.
    • Health items with configurable effects.
    • Gun attachments for weapon customization.
    • Loot boxes with randomized rewards.
  • Data-Driven Architecture
    • Item and gameplay parameters are managed through Unreal Engine Data Tables.
    • Centralized configuration makes it easier to add and modify items.
    • New item types can be introduced without restructuring the core inventory system.
    • Designed for rapid iteration and content expansion.

Technical Focus

The system focuses on creating a reusable interaction and inventory architecture rather than implementing these mechanics as project-specific logic. Interaction detection, item handling, inventory management, and pickup behavior are structured as modular systems that can be adapted to different gameplay requirements.

The result is a flexible foundation for FPS/TPS games, survival games, RPGs, battle royale projects, and open-world experiences requiring robust interaction and inventory mechanics.
