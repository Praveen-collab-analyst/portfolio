Map & Minimap System

A modular Map & Minimap System for Unreal Engine 5, designed to provide real-time navigation and world awareness for shooter, survival, RPG, and open-world projects. The system combines a responsive minimap, expandable world map, compass tracking, actor markers, and synchronized location indicators into a unified navigation framework.

Key Features

  • Real-Time Minimap
    • Displays the surrounding game world in real time.
    • Supports dynamic player and actor tracking.
    • Designed to provide continuous situational awareness during gameplay.
    • Easily customizable to match different game styles and UI layouts.
  • Expandable World Map
    • Full-screen map interface for detailed navigation.
    • Supports zoom and pan functionality.
    • Allows players to inspect larger areas of the game world.
    • Designed for both exploration and tactical navigation.
  • Dynamic Compass System
    • Real-time directional compass tracking.
    • Displays relevant players and gameplay actors.
    • Keeps navigation information synchronized with the map and minimap.
    • Provides quick directional awareness without opening the full map.
  • Actor Tracking System
    • Dedicated component for tracking custom actors on the map.
    • Supports different gameplay objects and points of interest.
    • Allows developers to define which actors should appear on the navigation interfaces.
    • Easily extendable for objectives, teammates, enemies, locations, and other gameplay elements.
  • Location Pinning
    • Players can place location markers directly on the map.
    • Pinned locations are reflected across the navigation system.
    • Map pins can be used for objectives, points of interest, or player-defined locations.
    • Synchronized indicators provide consistent navigation feedback.
  • Modular Architecture
    • The system is designed to separate map rendering, actor tracking, compass functionality, and player interaction, making individual components easier to customize and extend.
    • New marker types, tracked actors, navigation elements, and map interactions can be added without rebuilding the entire system.

Technical Focus

The primary focus of this project is building a complete navigation framework rather than a simple minimap widget. The system connects the minimap, full-screen map, compass, actor tracking, and location markers into a consistent navigation experience.

It provides a reusable foundation for FPS/TPS games, battle royale projects, survival games, RPGs, and open-world experiences where players need detailed and responsive world navigation.
