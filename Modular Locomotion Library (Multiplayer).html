ROSHAN

Modular Locomotion Library (Multiplayer)

A complete, modular, and data-driven UI framework for Unreal Engine 5, designed for modern shooter, survival, and battle royale-style games. The system provides a production-ready foundation for inventory, interaction, HUD, navigation, notifications, and player settings, allowing developers to build feature-rich interfaces without creating every system from scratch.

Key Features

  • Six Locomotion & Combat States
    • Sword & Shield
    • Bow & Arrow
    • Shotgun
    • Pistol
    • Rifle
    • Unarmed
  • Advanced Locomotion
    • Walk, jog, crouch, and jump with smooth animation blending.
    • Directional rolling based on player input.
    • Responsive transitions between different movement and combat states.
    • Animation-driven locomotion designed for third-person gameplay.
  • Melee & Ranged Combat
    • Sword-based melee combat with combo attacks.
    • Blocking system for sword and shield gameplay.
    • Bow and arrow combat with projectile-based attacks.
    • Firearm combat supporting pistols, rifles, and shotguns.
    • Weapon-specific reload mechanics.
  • Weapon Handling
    • Equip and unequip functionality.
    • Weapon-specific animation integration.
    • Automatic switching between different locomotion and combat states.
    • Support for both melee and ranged weapon workflows.
  • Dynamic Crosshair System
    • Fully functional real-time crosshair.
    • Automatically adapts based on the equipped weapon and combat state.
    • Designed to support different crosshair behaviors for different weapon types.
  • Modular Locomotion Architecture
    • New locomotion states can be added without modifying the core system.
    • Create a child Blueprint from ABP_LayerBase and assign animations to the provided placeholders.
    • Makes it easier to expand the framework with additional weapons, combat styles, and movement states.
  • Multiplayer & Performance
    • Fully Replicated — Designed with multiplayer gameplay in mind, with core locomotion and combat interactions working across server and clients.
    • Lightweight Architecture — Background calculations are handled through worker threads where appropriate, helping reduce unnecessary workload on the game thread.
    • Optimized for Scalability — Designed to provide responsive gameplay across different hardware configurations.

    Technical Focus

    The primary focus of this project is modular character architecture. Instead of hard-coding every movement or combat style into a single system, the framework separates locomotion states and animation layers so new gameplay styles can be introduced with minimal changes to the existing logic.

    The result is a reusable foundation for developers building third-person action games, RPGs, multiplayer combat games, and other projects that require multiple movement and combat styles.
