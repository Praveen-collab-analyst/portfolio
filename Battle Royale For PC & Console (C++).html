Battle Royale for PC & Console (C++)

A modular C++ shooter framework for Unreal Engine 5, developed as a foundation for building a complete PC and console battle royale experience. The project combines a clean C++ gameplay architecture with Blueprint-driven customization, allowing weapons, pickups, inventory items, and gameplay parameters to be configured without modifying the underlying C++ systems.

The framework focuses on building reusable shooter mechanics that can be extended into larger multiplayer experiences while keeping the core gameplay architecture organized and maintainable.

Key Features

  • Modular Weapon System
    • Supports rifles, pistols, and shotguns.
    • Weapon behavior is driven through the FWeaponData structure.
    • Damage, fire rate, ammunition, sounds, visuals, and other parameters are exposed for Blueprint configuration.
    • Designed to make creating new weapon variants quick and consistent.
  • Dual Weapon System
    • Equip both primary and secondary weapons.
    • Smooth weapon switching with animation support.
    • Modular architecture for integrating additional weapon types.
  • Inventory & Pickup System
    • World-based pickup system for weapons, ammunition, grenades, health items, and backpacks.
    • Inventory management for equipped weapons, consumables, and ammunition.
    • Backpacks dynamically increase available inventory capacity.
    • Designed around reusable pickup base classes.
  • Grenade System
    • Real-time grenade trajectory prediction.
    • Visual prediction path and throw endpoint.
    • Ability to cancel grenade throws.
    • Physics-based grenade explosions with configurable behavior.
  • Health & Consumable System
    • Health recovery through consumable items such as bandages and energy drinks.
    • Configurable healing values exposed to Blueprint.
    • Designed for easy balancing and extension with additional consumables.
  • Dynamic Crosshair
    • Real-time crosshair feedback based on player movement and shooting.
    • Provides visual feedback during different weapon and movement states.
    • Designed to support different weapon-specific crosshair behaviors.
  • Weapon Wheel
    • Radial weapon-selection interface.
    • Allows players to quickly switch between available weapons.
    • Integrated with the inventory and dual-weapon systems.
  • Player Locomotion
    • Walking, sprinting, crouching, and jumping.
    • Smooth movement transitions and animation blending.
    • Integrated with the weapon and combat systems.

C++ Architecture

The project includes 18 core C++ classes with Blueprint-derived children, providing a structured foundation for extending the gameplay systems.

Key classes include:

  • APlayerCharacter — Core player movement, inventory, and combat logic.
  • AWeaponBaseActor — Base class for all weapon types.
  • AShotgunBase — Shotgun-specific firing and spread behavior.
  • ABulletBase — Projectile logic with configurable velocity and visuals.
  • ABulletShellBase — Ejected shell actor for weapon feedback.
  • UGrenadeSystem — Grenade trajectory prediction and throwing logic.
  • AGrenadeBase — Grenade actor and explosion behavior.
  • APickupBase — Base class for world pickups.
  • AAmmoBase — Ammunition pickup handling.
  • AHealthKitBase — Base class for health consumables.
  • ABagpackBase — Backpack system for increasing inventory capacity.
  • AGrenadeSplineEndPointBase — Grenade trajectory endpoint visualization.

Technical Focus

The primary focus of this project is modular C++ gameplay architecture. Core systems are implemented in C++ while gameplay parameters are exposed to Blueprint, creating a workflow where developers can build and balance weapons, pickups, consumables, and other gameplay elements without repeatedly modifying the underlying code.

The framework demonstrates practical experience with Unreal Engine C++ gameplay programming, modular class architecture, weapon systems, inventory, pickups, projectiles, grenades, player locomotion, and Blueprint-C++ integration.
