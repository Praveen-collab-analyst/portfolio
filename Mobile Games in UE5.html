ROSHAN

Mobile Games in UE5

A collection of eight fully functional casual mobile games built entirely in Unreal Engine 5 Blueprints, created to explore lightweight mobile game development without switching to another engine. The project focuses on practical mobile optimization, simple gameplay systems, and reusable Blueprint architecture suitable for rapid casual game development.

Designed with a mobile-first approach, the project demonstrates how Unreal Engine can be used beyond high-end PC and console experiences to create lightweight games capable of running smoothly on older Android hardware.

Included Games

  • Color Ball Sort — Sort colored balls into matching tubes using simple drag-and-drop gameplay.
  • Jigsaw Puzzle — Assemble images through a scalable drag-and-drop puzzle system.
  • Sliding Block Puzzle — Move blocks strategically to create a path toward the objective.
  • Merge Fruits — Combine falling fruits to progressively create larger fruits and ultimately reach the watermelon.
  • Sudoku — A number-based puzzle system designed for repeatable gameplay.
  • Color Nut Sort — Organize and match colored nuts into their corresponding containers.
  • Jigsaw Sliding Block — A hybrid puzzle combining jigsaw and sliding-block mechanics.
  • Flappy Bird Clone — A side-scrolling endless-tap game focused on simple, responsive controls.

Technical Highlights

  • Unreal Engine 5.5.4
  • 100% Blueprint-based — No C++ required.
  • Clean and modular Blueprint architecture.
  • Extensive comments and organized, color-coded Blueprint categories.
  • Designed specifically around mobile performance and low hardware requirements.
  • Tested on older Android hardware, including devices using the Kirin 659 chipset.
  • Gameplay systems structured to be reusable and easy to extend.

Mobile Optimization

A major focus of the project is demonstrating that Unreal Engine can be used effectively for lightweight casual mobile games when the project is designed with performance in mind.

The games use simplified gameplay systems and optimized Blueprint logic to maintain responsive performance on lower-end Android hardware, making the project useful as a reference for developers learning how to approach mobile optimization within Unreal Engine.

Technical Focus

The project demonstrates practical techniques for building small, self-contained mobile games quickly, while keeping the underlying Blueprint architecture organized and reusable.

It is particularly useful for Unreal Engine developers who primarily work on PC, console, or high-end games and want to explore casual mobile development, rapid prototyping, and mobile optimization without moving to another game engine.
