Dynamic Compass System

A highly advanced dynamic compass system for Unreal Engine 5, inspired by modern AAA shooter interfaces such as Call of Duty. The system goes beyond basic directional navigation by providing real-time tracking for enemies, custom gameplay actors, and player-defined locations, giving players continuous tactical awareness without opening the map.

Key Features

  • Dynamic Compass Interface
    • Real-time directional compass that continuously updates based on player orientation.
    • Smoothly displays relevant actors and points of interest around the player.
    • Designed to provide a clean, information-rich navigation experience inspired by modern shooter HUDs.
  • Custom Actor Tracking
    • Track customizable gameplay actors directly on the compass.
    • Supports enemies, teammates, objectives, points of interest, and other gameplay-relevant actors.
    • Actor tracking can be configured based on the requirements of the project.
    • Designed to support different marker types and tracking behaviors.
  • Enemy Tracking
    • Displays tracked enemies and hostile actors directly on the compass.
    • Provides players with directional awareness of threats outside their immediate field of view.
    • Can be integrated with AI and gameplay systems to dynamically determine which actors should be displayed.
  • Map & Compass Synchronization
    • Player-created map pins are automatically represented on the compass.
    • A location marked on the minimap can be tracked directionally without opening the full map.
    • Keeps navigation information consistent between the minimap and compass.
  • Dynamic Location Markers
    • Supports customizable markers for different gameplay purposes.
    • Markers dynamically move across the compass as the player rotates.
    • Supports multiple simultaneous tracked locations and actors.
  • Modular Tracking Architecture
    • Tracking functionality is separated from the compass UI.
    • New actor types and marker behaviors can be added without rebuilding the core compass system.
    • Designed to integrate with existing AI, navigation, objective, and map systems.

Technical Focus

The primary focus of this project is creating a dynamic tactical navigation system rather than a simple compass widget. The compass acts as a centralized directional information layer, connecting player orientation with tracked actors, enemies, objectives, and map locations.

The system is particularly suited for FPS/TPS games, battle royale projects, tactical shooters, survival games, and open-world experiences where real-time directional awareness is an important part of the gameplay.
