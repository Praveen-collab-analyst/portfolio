ROSHAN

Ultimate UI Framework

A complete, modular, and data-driven UI framework for Unreal Engine 5, designed for modern shooter, survival, and battle royale-style games. The system provides a production-ready foundation for inventory, interaction, HUD, navigation, notifications, and player settings, allowing developers to build feature-rich interfaces without creating every system from scratch.

Key Features

  • Inventory System
    • Fully functional inventory with drag-and-drop support.
    • Item categorization and dynamic inventory capacity.
    • Backpack-based capacity progression.
    • Data-driven item configuration for easy customization.
  • Advanced Interaction System
    • Six configurable interaction modes.
    • Supports both focus-based and proximity-based detection.
    • Instant interaction or hold-to-interact functionality.
    • Flexible interaction logic that can be adapted to different gameplay scenarios.
  • Pickup & Loot System
    • Weapon pickups with support for multiple weapon categories.
    • Multiple ammunition types linked to specific weapons.
    • Different grenade types with configurable functionality.
    • Health items with customizable effects.
    • Gun attachments for weapon customization.
    • Loot boxes with randomized rewards.
  • Shooter HUD
    • Dynamic crosshair system with contextual feedback.
    • Player health and status display.
    • Equipped weapon and ammunition information.
    • Quick-access inventory interface.
    • Designed around modern shooter-style HUD layouts.
  • Compass & Navigation System
    • Real-time compass tracking for players and gameplay actors.
    • Minimap with zoom and pan functionality.
    • Expandable full-map interface.
    • Custom actor tracking through a dedicated component.
    • Location pins synchronized between the compass and map.
  • Notification System
    • Displays important gameplay events and player status information.
    • Supports events such as eliminations and remaining player counts.
    • Structured to support additional alerts, timers, and gameplay notifications.
  • Settings & Controls Menu
    • Multi-tab interface for different player options.
    • Graphics, resolution, audio, and quality settings.
    • Full key rebinding support.
    • Inventory and map interfaces.
    • Integrated quit option.
  • Technical Highlights
    • Fully Data-Driven Architecture using Unreal Engine Data Tables.
    • Centralized configuration for gameplay and UI parameters.
    • Modular systems designed for easy extension and customization.
    • Clean and organized project structure following Unreal Engine conventions.
    • Compatible with Unreal Engine 5.4 – 5.8.

Data-Driven Customization

The major systems are controlled through Data Tables, allowing weapons, ammunition, grenades, health items, attachments, and other gameplay parameters to be configured without modifying the underlying UI logic.

This approach makes the framework easier to maintain and allows developers to rapidly iterate on content while keeping the core systems reusable.

Technical Focus

The primary focus of this project is building a scalable UI architecture rather than a collection of isolated widgets. Inventory, interaction, navigation, HUD, notifications, and settings are designed to work together as a unified framework while remaining modular enough to be extended independently.

The result is a reusable UI foundation for first-person and third-person shooters, battle royale games, survival games, and open-world projects that require a complete and customizable player interface.
